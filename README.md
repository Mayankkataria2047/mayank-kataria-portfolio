Personal resume and portfolio website built with plain HTML5 and CSS3 (no frameworks, no JavaScript).

- **Programme:** BBA Digital Business and Entrepreneurship, IIM Bangalore
- **Course:** Website Development, Mid-Term Project

## Structure
```
resume-website/
├── index.html
├── style.css
├── README.md
└── assets/
    ├── profile.jpg
    └── icons/favicon.svg
```

## Run locally
Open `index.html` in any browser. Fonts (Manrope, Inter) load from Google Fonts when online.

## Hosting
Hosted with GitHub Pages (Settings > Pages > Deploy from branch `main`, folder `/ (root)`).

## Note on the contact form
GitHub Pages is static hosting, so the form is a design demonstration and does not send messages. A backend or an external form service would be required.
